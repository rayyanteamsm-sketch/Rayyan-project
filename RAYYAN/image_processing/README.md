# معالجة صور ريّان كمصفوفات NumPy

يفحص مجلد الصور الأصلية للمشروع (`data/processed/images/originals`) وكل مجلداته الفرعية،
ويحوّل كل صورة (PNG وJPG وHEIC) إلى مصفوفة NumPy ويعالجها، ويحفظ النتائج في `image_processing/output`.
**الصور الأصلية تُقرأ فقط ولا تُعدَّل**، ويتحقق البرنامج من بصمتها SHA-256 قبل التشغيل وبعده.

## التشغيل

```powershell
cd image_processing
py -m pip install -r requirements.txt
py main.py                                  # المجلد الافتراضي
py main.py "مسار مجلد آخر" -o results --size 256
```

## الملفات

| الملف | وظيفته |
|---|---|
| `scanner.py` | يحصر الصور في كل المجلدات الفرعية، ويربطها بمجموعتها من `manifest.json`، ويعامل `X_converted.jpg` كنسخة مشتقة من `X.HEIC` لا كصورة إضافية |
| `loader.py` | يحوّل الصورة إلى مصفوفة RGB `uint8` ويصحح اتجاه صور الجوال؛ HEIC عبر pillow-heif ← ffmpeg ← النسخة المحوّلة |
| `heic.py` | قراءة HEIC عبر ffmpeg (من النسخة السابقة دون تغيير) |
| `processing.py` | عمليات المصفوفات: رمادي، توحيد المقاس، تطبيع، قناع الأخضر، الحواف، الإحصاءات (من النسخة السابقة دون تغيير) |
| `main.py` | التشغيل الكامل وحفظ النتائج |
| `test_program.py` | الاختبارات (17 اختبارًا، منها تشغيل على الصور الحقيقية) |

## النتائج في `output/`

- `processed/<المجموعة>/<الصورة>/`: `gray.png` و`green_mask.png` و`edges.png` و`resized_512.png`.
- `images_uint8.npy`: كل الصور في مصفوفة واحدة `(12, 512, 512, 3)`؛ تُوحَّد الأبعاد بالتصغير مع الحفاظ على النسبة ثم الحشو بالأسود.
- `images_float32.npy`: المصفوفة نفسها بقيم من 0 إلى 1، وترتيب الصور في `images_index.json`.
- `report.csv`: المجموعة، والصيغة، وطريقة القراءة، والأبعاد، ومتوسط كل لون، والسطوع، والتباين، ونسبة الغطاء الأخضر.
- `summary.json`: ما عولج، وما فشل وسببه، والملفات غير المدعومة، و`originals_unchanged`.

## الأخطاء

- الملف التالف يُسجَّل في `summary.json` ويكمل البرنامج بقية الصور.
- الملفات غير المدعومة تُذكر وتُتخطى.
- يرفض البرنامج أن يكون مجلد الإخراج داخل مجلد الصور الأصلية.

## الاختبارات

```powershell
py -m pytest test_program.py -v
```

نسبة الأخضر مؤشر لوني تقريبي (Excess Green بحد 0.10)، وليست قياسًا زراعيًا؛ قد تحسب الأجسام الخضراء غير النباتية،
أو تخطئ في الظلال الداكنة والأوراق الجافة.
