# بطاقة نموذج الاستجابة — محاكاة فقط

المهمة Regression لأن الهدف كمية متصلة: `delta_vwc=post_vwc-pre_vwc` بوحدة m³/m³. يصدر التنبؤ04:00 محليًا، والتقييم عند النهاية المخططة+120دقيقة. أفقه من القرار يتغير حسب موعد البدء والمدة المعروفين مسبقًا؛ ليس ساعتين ثابتتين من وقت القرار.

Ground Truth الحالي عينات حساسات مولدة مع ضجيج ومفقود، وليست قياسات ميدانية مستقلة. متوسط عينتين أو ثلاث حول الهدف±5دقائق ناقص العينة المتاحة قبل القرار. توجد769 نتيجة صالحة، ونتيجة ناقصة واحدة بقيت NULL ولم تدخل التدريب.

المدخلات العددية التي يستخدمها الكود فعلًا:

| Feature | متى تتاح؟ |
|---|---|
| `pre_vwc` | عينة معايرة وصلت قبل القرار |
| `planned_volume_l`, `planned_duration_min` | من الخطة المحفوظة وقت القرار |
| `root_depth_m`, `area_m2` | خصائص افتراضية ثابتة معروفة مسبقًا |
| `forecast_rain_mm`, `forecast_et0_mm` | إصدار توقع اصطناعي متاح03:01 قبل القرار04:00 |
| `doy_sin`, `doy_cos` | من تقويم وقت القرار |

المعرفات وzone_id وأوقات الإتاحة Metadata للربط والتقسيم، ولا تدخل تلقائيًا في النموذج. لا يدخل الحجم المنفذ أو النهاية الفعلية أو post_vwc أو delta_vwc أو scenario_id أو confirmed_cause أو الطقس المتحقق لاحقًا. Features وTargets منفصلان، و`feature_availability` يتتبع وصول مصادر المدخلات.

إعادة التحليل نُزلت في2026، فلا تُعامل كطقس مستقبلي متاح في2024–2025. التوقعات المستخدمة محاكاة معلنة مشتقة من forcing مع خطأ افتراضي؛ ليست أرشيف توقعات فعلية، ولا تصلح لتقييم مهارة مزود طقس.

التقسيم:2024 تدريب؛ يناير–يونيو2025 تحقق؛ يوليو–ديسمبر2025 اختبار. العملية كاملة في Split واحد، ووسوم كل جزء متاحة قبل بداية التالي. أعداد الوسوم الصالحة في `demo_model_card.json`. نفس الموقع والمنطقتين موجودان في الأجزاء الثلاثة؛ لا يوجد اختبار موقع مستقل.

نُفذ Baseline لعدم التغير، وRandom Forest بإعدادات ثابتة مسجلة. المقاييس MAE وRMSE بوحدة VWC وR² بلا وحدة، وليست Accuracy. قورن نموذج مجمد متدرب على2024 بنسخة محدثة تدربت أيضًا على النصف الأول2025، على نفس اختبار النصف الثاني2025. النتائج في `quality/demo_model_metrics.csv`، والتنبؤات في `demo_predictions.csv`. لا نشر تلقائي ولا أوامر أجهزة من النموذج.

نتائج الاختبار تبين تعلم بيانات المحاكاة فقط؛ لا تثبت دقة ميدانية أو مثالية جرعة أو توفيرًا. حتى تحسن النسخة المحدثة لا يثبت تحسنها خارج المحاكي.

للحقيقة الميدانية: حساسات ممثلة معايرة مقابل مرجع مستقل، ونافذة استجابة يثبتها المختص الزراعي قبل القياس، وسجلات مطر وتدخلات وفشل تشغيل. يؤكد المختص صلاحية بروتوكول النتيجة، ويؤكد الفني أسباب الأعطال. جودة النبات تحتاج صورًا وفحصًا مستقلًا عن الحساس والمحاكي.

البديل دون وسوم موثوقة: قواعد رطوبة وتوازن ماء بخصائص وتدفق معتمدين محليًا، مع مراجعة بشرية ومراقبة التنفيذ. الجرعات المنفذة ليست وسوم الجرعات المثلى. لتعلم الجرعة لاحقًا يلزم تعريف نجاح زراعي واضح وقياس الماء وصحة النبات وتجربة خطط متنوعة ضمن حدود معتمدة.

للتقييم الحقيقي: حالات جفاف وبلل ومطر وعجز ماء، وأحداث مستقلة عبر مواسم وتربة مختلفة، واختبار زمني لاحق ثم قطع ومواقع جديدة. تُستخدم منحنيات التعلم وخطأ مقسم حسب الحالة، لا عدد صفوف ثابت. منطقة واحدة لكل ذراع لا تقدم تكرارًا مستقلًا لإثبات الأثر السببي.
