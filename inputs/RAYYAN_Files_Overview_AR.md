# أوفر فيو ملفات ريّان — دليل كل ملف في الحزمة

هذا الدليل يشرح **كل الملفات الـ97** الموجودة فعلًا داخل `Rayyan_Data_Package_2024_2025.zip`، بحسب النسخة المسلّمة في 7 نوفمبر 2026. يشمل وظيفة الملف، وعدد صفوف CSV، وأولوية استخدامه. لم أغيّر الحزمة أو البيانات أثناء إعداد الشرح.

## ابدئي من هذه الملفات

| الترتيب | الملف | لماذا أفتحه؟ |
|---:|---|---|
| 1 | `README_AR.md` | فهم الحزمة والنطاق والقيود. |
| 2 | `MODEL_CARD_AR.md` | معرفة ما يتعلمه النموذج وما الذي لا تثبته نتائجه. |
| 3 | `metadata/data_dictionary.csv` | فهم أسماء الأعمدة والوحدات. |
| 4 | `data/ml/ml_features.csv` | تجهيز المدخلات X. |
| 5 | `data/ml/ml_targets.csv` | تجهيز الهدف y: العمود`delta_vwc`. |
| 6 | `data/ml/split_manifest.csv` | استخدام التقسيم الزمني وفلترة`eligible`. |
| 7 | `code/train_demo.py` | تشغيل تجربة RandomForestRegressor الجاهزة. |
| 8 | `quality/demo_model_metrics.csv` | قراءة MAE و RMSE و R² بعد التدريب. |

التدريب الحالي يتعلم **تغير رطوبة التربة استجابة لخطة ري**: `delta_vwc = post_vwc - pre_vwc`. الحجم المخطط`planned_volume_l` مدخل، وليس الهدف. توجد 770 عملية في ملفات ML، منها 769 صالحة:384 تدريبًا، و 183 تحققًا، و 202 اختبارًا. الباقية ذات Target ناقص وتستبعد حسب`eligible=False`.

البيانات التشغيلية محاكاة معلّمة، والطقس التاريخي إعادة تحليل شبكية، والمراجع المنشورة منفصلة. صلاحية التدريب الحالية تجريبية؛ لا توجد Labels ميدانية مستقلة تثبت دقة تشغيل حقيقي أو كمية ري مثلى أو توفير ماء.

CSV و SQLite يحويان الجداول كاملة. Excel للمراجعة وفيه 43 ورقة؛ أربع سلاسل كبيرة جزئية بنطاق موثق في`quality/excel_review_manifest.csv`، بينما Features و Targets والقرارات والأحداث كاملة.

## معنى امتدادات الملفات

| الامتداد | معناه في الحزمة |
|---|---|
| `.csv` | جدول يمكن فتحه بـExcel أو قراءته بـpandas. جميع CSV بترميز UTF-8. |
| `.json` | معلومات منظمة: إعدادات أو بيانات أو نتائج تحقق، حسب اسم الملف. |
| `.py` | كود Python. |
| `.mjs` | كود JavaScript يعمل ببيئة Node. |
| `.md` | توثيق نصي Markdown، يمكن قراءته في VS Code أو عارض Markdown. |
| `.xlsx` | مصنف Excel للمراجعة. |
| `.sqlite` | قاعدة بيانات كاملة يمكن الاستعلام منها بـSQL. |
| `.pdf` | تقرير المشروع الأصلي. |
| `.txt` | متطلبات مكتبات أو بصمات تحقق، حسب اسم الملف. |

عدد الصفوف في الجداول الآتية لا يشمل صف العناوين. داخل`field_templates` عدد الصفوف صفر؛ لا تستخدميها باعتبارها بيانات تدريب.

## كيف ترتبط ملفات التدريب؟

تربطين`ml_features.csv` و`ml_targets.csv` و`split_manifest.csv` باستخدام`decision_id`. بعد الدمج تستبعدين`eligible=False` والوسم المفقود، ثم تختارين قائمة Features العددية التي يحددها كود التدريب. المعرفات وأوقات الإتاحة ليست Features تلقائية لمجرد وجودها في الملف.

|---|---|
| `pre_vwc` | الرطوبة السابقة المتاحة وقت القرار. |
| `planned_volume_l`, `planned_duration_min` | كمية الري ومدته المخططان، معروفان قبل التنفيذ. |
| `area_m2`, `root_depth_m` | خصائص المنطقة والجذور المفترضة بالحزمة. |

`event_outcomes.csv` يوضح أصل الإجابة: آخر رطوبة متاحة وقت القرار ومتوسط عينات حول النهاية المخططة+120 دقيقة، بشرط وجود عينتين صالحتين على الأقل من ثلاث. المطر أو العطل أثناء النافذة يسجل كمربك لاحق، وليس مدخلًا معروفًا مسبقًا.

## أقل مسار لتجربة التدريب

افتحي المجلد الذي يحتوي`requirements.txt` بعد فك ZIP. لا تحتاجين إعادة توليد البيانات أو بناء SQLite أو Excel للبدء:

```bash
python -m pip install -r requirements.txt
python code/validate_dataset.py
python code/train_demo.py
```

الكود يستخدم Train لسنة 2024، و Validation للنصف الأول 2025، و Test للنصف الثاني 2025. يحفظ النتائج في`quality/demo_model_metrics.csv` والتنبؤات في`quality/demo_predictions.csv`. لا حاجة لخلط السجلات عشوائيًا أو إنشاء تقسيم جديد قبل فهم التقسيم الموجود.

تشغيل أكواد التوليد أو التدريب قد يعيد كتابة مخرجات داخل الحزمة. احتفظي بنسخة أصلية، واشتغلي على نسخة للتجربة. اختلاف SHA256 بعد تعديل مقصود يعني أن الملف تغير عن النسخة المسلمة، وليس حكمًا آليًا بأن التعديل خطأ.
